# Student Dashboard

A responsive and modern Student Dashboard built using React, HTML, CSS, and JavaScript. This project helps students manage academic activities like attendance, assignments, marks, fees, study materials, and placement opportunities through a clean user interface.

## Features Implemented

### Authentication
- Login functionality using LocalStorage
- Logout functionality

### Dashboard
- Welcome section
- Summary cards
- Timetable
- Attendance overview

### Student Modules
- Profile Page
- Attendance Management
- Assignments Section
- Study Materials
- Marks & Grades
- Fee Management
- Placement Opportunities

### UI Features
- Responsive design
- Sidebar navigation
- Top navbar
- Progress bars
- Cards and tables
- Mobile-friendly layout


## Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- React Router DOM
- React Icons
